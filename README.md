# 粵語音節文字（Cantonese Syllabic Script）

本文字系統是一套專為現代標準粵語（廣州話/香港粵語）設計的音節方塊文字。系統融合朝鮮諺文（Hangul）的組字幾何思維與日文假名、拉丁字母的造字筆畫，將粵語每個完整音節（聲、韻、調）規整於單一等寬方塊之內，既具備拼音文字的表音準確性，又保留漢字的方塊閱讀節奏與版面美感。

---

## 一、字符組成要素

一套完整的粵語音節字符由四個核心部件構成：初聲（聲母）、中聲（元音/韻腹）、終聲（尾音/韻尾）及調符（聲調）。

### 1. 初聲（聲母，19個）
聲母固定置於字塊之左上方：
* **塞音與塞擦音**：
  * b (ㅂ), p (ㅍ), d (ㄷ), t (ㅌ), g, k
  * z, c
  * 圓唇化軟顎音：gw (ヲ上加一橫), kw (ヲ上加橫折)
* **鼻音與邊音**：
  * m, n, ng, l (ㄹ)
* **擦音與半元音**：
  * f (フ), s, h, w (ワ), j

### 2. 中聲（元音與韻腹）
元音固定置於字塊之右上方或頂部：
* **基礎單元音**：
  * a (短 a), i, u, e, o
  * yu (ㅠ，細音圓唇元音，如「於」)
* **長元音專用符**：
  * aa (用於與短 a 作音值區分，如「三」之韻腹)
* **二合雙元音拼合律**：
  * 採「前元音 + 後元音」在右上方格內左右緊湊拼合。
  * 如 ai, au, ei, oi, ou, ui, iu。
  * 長音二合：aai, aau。
  * 特殊圓唇複合音：oe, eo, eoi (如「水、去」)。

### 3. 終聲（尾音/韻尾，6個輔音）
本系統採取「初終同符」原則：所有尾音均直接複用初聲（聲母）字符，置於字塊之左下方：
* **鼻音韻尾**：-m, -n, -ng
* **入聲塞音韻尾**：-p (ㅍ), -t, -k

### 4. 調符（聲調，6個幾何標記）
調符固定置於方塊之右下方或底部，嚴格對應粵語六個調值，直接整合進方塊結構內部：
* 第 1 聲（陰平 55/53）
* 第 2 聲（陰上 35）
* 第 3 聲（陰去 33）：ウ
* 第 4 聲（陽平 21/11）
* 第 5 聲（陽上 13/23）
* 第 6 聲（陽去 22）：リ
* **入聲歸調準則**：帶入聲尾（-p, -t, -k）之音節依其調值歸併，上陰入（7 聲）取 1 聲調符，下陰入（8 聲）取ウ（3 聲調符），陽入（9 聲）取リ（6 聲調符）。

## 二、拼字結構與位置規範

本文字系統依照音節所包含的部件，分為以下七種字形結構：

1. **第一種：只有母音（元音）**
   * 母音直接佔據整個方塊。
2. **第二種：只有聲母**
   * 聲母（成音節鼻音）直接佔據整個方塊。
3. **第三種：母音 + 聲調**
   * 母音放在上方，聲調放在下方。
4. **第四種：聲母 + 聲調**
   * 聲母（成音節鼻音）放在上方，聲調放在下方。
5. **第五種：聲母 + 母音 + 聲調**
   * 聲母放在左上方，母音放在右上方，聲調放在下方。
6. **第六種：母音 + 尾音 + 聲調**
   * 母音放在上方，尾音放在左下方，聲調放在右下方（或下方右側）。
7. **第七種：聲母 + 母音 + 尾音 + 聲調（四種齊全）**
   * 聲母放在左上方，母音放在右上方，尾音放在左下方，聲調放在右下方。

---

## 三、位置基本公理

1. **母音（元音）**：永遠只會固定出現在整個方塊或上方或右上方，絕不出現在左側或下方。
2. **聲母**：永遠只會固定出現在整個方塊或上方或左上方。
3. **尾音**：永遠只會固定出現在左下方。
4. **聲調**：永遠只會固定出現在下方或右下方。
